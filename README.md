# Friendify for Facebook

This project aims to provide an Android client for the facebook.com website.

## Features:

Browse your Facebook account:
- NewsFeed
- Friends
- Events
- Groups
- Albums
- Photos
- Notifications
- Messages
- Friend requests
- Profile
- Checkins

Post to Facebook:
- Likes
- Comments
- Status updates
- Photos
- New albums
- Checkins to nearby locations

Other features:
3D coverflow gallery.
statusbar notifications.

![Screen shots](https://github.com/GunnarKarlsson/friendify/raw/master/screenShots.png)


## Background

Friendify was launched on Google Play (then Android Market) in 2012. It was open-sourced in May 2013. 

Friendiy was offered in different versions, each with a unique patterns, including zebra skin, pink dots, purple etc.

The project was written in ActionScript 3.0 and mxml. It requires the Adobe air flash plugin to run on Android devices.
